## Central question

Como pueden onset, duracion, relacion inter-onset, posicion metrica, silencio y
colocacion de cambios restringir decisiones melodicas, armonicas y formales, y
que relaciones permiten filtrar o rankear alternativas en vez de describir
solamente estructura temporal?

## Scope and exclusions

Se estudia conocimiento de decision compositiva sobre onset, duracion, IOI,
rests, densidad, metro, posicion metrica, sincronizacion/divergencia de
cambios y relacion con forma.

No se estudia una teoria general de groove, cuantizacion MIDI, microtiming,
swing, patrones de bateria, tempo optimo, danceability o un modelo universal
de tension.

## Absolute distinctions

- `RHYTHM != METER`.
- `METER != TEMPO`.
- `TEMPO != EVENT DENSITY`.
- `EVENT DENSITY != IOI`.
- `ONSET != DURATION`.
- `DURATION != IOI`.
- `NOTATED DURATION != SOUNDING DURATION` automaticamente.
- `METRIC POSITION != ACCENT` automaticamente.
- `METRIC STRENGTH != PERCEPTUAL PROMINENCE` universalmente.
- `SYNCOPATION != TENSION != GROOVE != ENERGY`.
- `REST != BOUNDARY != CLOSURE`.
- `LONG NOTE != ARRIVAL != IMPORTANCE`.
- `SHORT NOTES != CONTINUATION`.
- `HIGH DENSITY != ENERGY` y `LOW DENSITY != CALM`.
- `MELODIC ONSET != HARMONIC ONSET`.
- `METRIC ARRIVAL != MELODIC ARRIVAL`.
- `METRIC ACCENT != FORMAL BOUNDARY`.
- `RHYTHMIC REPETITION != MEMORABILITY`.
- `RHYTHMIC VARIATION != DEVELOPMENT`.
- `QUANTIZED != MUSICALLY CORRECT`.

## Levels of temporal organization

| Nivel | Variables |
|---|---|
| event | onset, duration, IOI, rest |
| local pattern | rhythmic cell, attack pattern, repeated relation |
| metric | beat, subdivision, metric position, grouping |
| phrase/span | density trajectory, lengthening, compression, silence, boundary relation |
| harmonic timing | harmonic onset, harmonic duration, change rate |
| formal | phrase/section timing, arrival and boundary placement |

No se supone una jerarquia temporal universal ni que un nivel determine otro.

## Capability question

Para cada variable se pregunta:

- `CAN ENUMERATE`: generar alternativas estructurales;
- `CAN FILTER`: eliminar alternativas por restricciones declaradas;
- `CAN RANK`: preferir una alternativa sobre otra para un objetivo y alcance
  concretos.

La investigacion no presupone las respuestas.

## Inputs from zero

Un comienzo puede contener solo objetivo artistico/local, rol y escala formal,
metro declarado o supuesto, centro/coleccion si aplica, ventana temporal,
restricciones melodicas/armonicas y prosodia si existe. El metro ofrece un
contexto de posiciones y agrupacion; no entrega por si solo funcion,
prominencia, tension o importancia formal.

## Popular and common-practice scope

La practica comun aporta marcos delimitados para jerarquia metrica,
anacrusa, ritmo de frase, continuacion y colocacion cadencial. Caplin no se
trata como sintaxis universal.

La musica popular es obligatoria en el alcance: anticipaciones, desplazamiento
metrico, sincopa, capas metricas, loops, cambios armonicos y alineacion o
desplazamiento de frases. Los corpus y experimentos disponibles no sostienen
recetas universales, ni transfieren automaticamente groove, sincopa o densidad
a energia, continuacion o forma.
