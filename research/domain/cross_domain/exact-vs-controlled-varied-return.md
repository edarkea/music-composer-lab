# Exact Return vs Controlled Varied Return

## Estado

Sintesis de `RQ-CROSS-003`. Es investigacion comparativa de reconocimiento
melodico, no una regla general de forma ni una teoria de retorno formal.

## Resultado

El constructo es util con alcance: `recognition`, `similarity`,
`same/different`, `familiarity`, `memory accuracy`, `motivic identity`,
`formal return`, `memorability` y `liking` deben mantenerse separados.

La evidencia permite algunos rankings especificos:

- version intacta > distorsion que conserva contorno e intervalos relativos,
  bajo el paradigma inspeccionado de melodias folk familiares;
- contorno + intervalos relativos > contorno solo, bajo ese mismo alcance;
- contorno + chroma preservados > variantes que violan esos cues, en melodias
  nuevas aprendidas.

Estos resultados no rankean “exact return” frente a “variation generally”.

## Representation and variation

Exactness depende de la representacion: pitch absoluto, intervalos, contorno,
ritmo, onsets, registro y armonia no son una sola variable. Una variante
controlada cambia una dimension declarada y conserva invariantes declaradas.

La transposicion cambia pitch absoluto pero puede conservar relaciones
intervalicas y contorno. No es automaticamente exacta ni variada: depende de
la representacion y tarea.

## Dimension findings

| Dimension | Evidence state |
|---|---|
| transposition | recognition survives in some tasks; representation-dependent |
| pitch / interval | direct recognition evidence with bounded comparisons |
| contour | supports partial recognition, not identity guarantee |
| rhythm | similarity evidence, insufficient direct identity ranking |
| metric displacement | no sufficient direct identity evidence |
| register | isolated effect unresolved |
| changed ending | no sufficient direct comparison |
| ornamentation | no sufficient direct comparison |
| harmonic recontextualization | no sufficient direct comparison |

Prince is especially important as a safeguard: its factorial evidence concerns
perceived similarity, and the relative contribution of rhythm and contour
changes with listening conditions. Similarity cannot silently become identity.

## Structure -> perception -> composition

```text
STRUCTURE: exact/varied relation
PERCEPTION: recognition, same/different or similarity task
COMPOSITION: choose a recurrence strategy
```

Recognition does not establish better music, memorability, formal return or
global compositional success. Formal return does not establish perceptual
recognition.

## Phase-2 capability

- enumerate variants: `YES WITH SCOPE`;
- filter variants: `YES WITH SCOPE`;
- rank exact vs one specified variant on recognition: `YES WITH SCOPE`;
- rank exact vs variation generally: `NO`.

The result is partially positive comparative decision knowledge, not a global
preference for exact recurrence.

## Audited candidate and limits

`CAND-CROSS-003` records one scoped positive comparison. Audit outcome:
`REVISE`; readiness: `POSSIBLE_WITH_SCOPE`; phase-2 type:
`COMPARATIVE_DECISION_KNOWLEDGE`.

The candidate's safest claim is not “exact return beats varied return”. The
inspected result is a laboratory recognition comparison: intact/original
stimuli were compared with specified distortions, and preservation of contour
plus relative intervals outperformed contour-only preservation in the
familiar-folk paradigm. The intact condition is a source baseline, not by
itself evidence for a compositional exact return.

`Recognition` is retained as the measured construct. It is not silently
relabelled as perceptible identity, similarity, memory accuracy,
memorability, formal return, or compositional success. Massaro's learned-new-
melody result remains a separate bounded comparison; Prince is contextual
similarity evidence, and McAdams/Matzkin is conceptual review support.
The direct evidence is laboratory recognition of isolated or familiar
melodies, not formal return in a phrase, section or full song. Transfer to
popular-song recurrence is `UNKNOWN TRANSFER`.

Source-to-composition transfer is `PARTIAL`; transfer to formal return is
`NOT ESTABLISHED`. No ranking is supported for rhythm change, register,
changed ending, ornamentation, harmonic recontextualization, or formal scale.

Experiment gate remains `NOT JUSTIFIED`: the audited literature already
supports the specific recognition comparisons, while the unresolved questions
concern different targets—formal recurrence, popular-song scale, rhythm,
register, changed endings, harmony, and the relation between recognition and
identity.
