# EXP-003 — Practice assets v1

Se requieren exactamente dos assets no confirmatorios:

- `DEPLOY-PRACTICE-01`: repetición de una misma sonoridad entre R1 y R2.
- `DEPLOY-PRACTICE-02`: cambio moderado entre dos sonoridades, sin extremo de
  registro ni contraste didáctico de movimiento.

Ambos usan cuatro pitches por sonoridad, el timing de interfaz de 2,000 s, la
misma familia tímbrica básica y velocity 96. No pertenecen a F01–F12, no tienen
respuesta correcta, no enseñan `LOW = menor distancia` y quedan fuera del
análisis experimental y del manifest canónico.

Cada uno recibe SHA-256 y validación técnica independientes.
